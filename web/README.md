这是一个基于 [Next.js](https://nextjs.org) 构建的项目。

## 快速开始

先启动开发服务器：

```bash
npm run dev
# 或
yarn dev
# 或
pnpm dev
# 或
bun dev
```

在浏览器中打开 [http://localhost:3000](http://localhost:3000) 查看效果。

你可以通过修改 `app/page.tsx` 开始编辑页面，保存后页面会自动刷新。
