## 4. 已知限制

1. **无对话持久化**：REPL 退出后上下文丢失；`--resume` 未实现（留给 M2）
2. **无 Token 计数**：`auto-compact` 阈值还没落地，超长会话会直接失败（M1 补）
3. **Bash deny-list 简陋**：只挡了 8 种硬编码模式，不做 taint 追踪
4. **Windows 未覆盖**：`Bash` 直接 `shell=True`，Windows 体验未测（DESIGN §11 已决策 v1 只保 macOS/Linux）
5. **不支持多模态**：`Read` 遇到 PNG/PDF 返回 `[binary, N bytes]` 占位（DESIGN §11 已决策）
6. **测试未覆盖 Ctrl-C 中断语义**：loop 里的 `[interrupted]` 补灌代码存在但只靠手动验证
